# Community reputation

Users can label a URL:

- Mark as Scam
- Mark as Risky
- Mark as Safe

Stored as `user_reports` (authenticated, 24-hour duplicate block, 20 reports/day).

`domain_reputation` aggregates counts. The UI says:

> Community reports indicate elevated risk. This is not proof.

Community Trust is Unknown / Limited / Mixed / Low from volume and consistency — not absolute truth.

Reports are **not** used to retrain the production model automatically.
