3. Architecture

Extension / React
    REST JSON   POST /api/v1/threat/check-url
        FastAPI :8000
            URLChecker + psychology + intel + ads
                SQLite  threats.db
            JSON: score, simple_view, technical_view

Beginner: You paste a link or open a website. Our server checks it and warns you in simple English.

Technical: Multi-signal rule engine plus live lists (Safe Browsing if a key is set, else OpenPhish), DNS, RDAP age, brand impersonation, Hinglish psychological phrases, and aggressive-ad HTML sampling. React and the extension are clients of one FastAPI process.

Jury tip: If they draw Flask to Postgres to CNN, redraw FastAPI to SQLite to rules. Offer Postgres and a trained model as the roadmap.

4. check-url pipeline

  1. Pydantic body: url, view = both / simple / technical
  2. Trim; add https:// if missing
  3. Analyze: DNS, intel, age, phishing fragments, piracy, ads, brand, TLD, keywords, IP, length, HTTPS, psychology
  4. Cap score at 100. LOW under 30, MEDIUM under 50, HIGH under 70, else CRITICAL
  5. Trusted sites such as google.com return 0 if the domain exists
  6. Insert url_checks (user_id not set; ml_confidence stays 0)
  7. HIGH/CRITICAL also insert threats
  8. Return Simple View and/or Technical View

Other APIs: /health, /api/v1/threat/check-message (no dashboard UI), stats, signup, login, profile.

Warning: average_response_time_ms = 245 is hardcoded. Do not call it a measured SLA.

6. Database (SQLite, not PostgreSQL)

TablePurpose
usersusername, email, bcrypt password hash
url_checksscanned URL, score, level; user_id unused

SQL injection defense: parameterized ? queries. Two users at once: SQLite serializes writes. Database down: API 500, extension says unavailable.

7. Machine learning honesty

METRIC NOT YET AVAILABLE. No dataset file, no train/test split, no confusion matrix, no CNN.

If asked for ML theory: accuracy alone is dangerous because a dummy “always SAFE” model can look accurate. Recall matters more for phishing. A future model can use the same features we already score by rules. The ml_confidence column is reserved.

Must know: “Act now” on a real sale is not automatically phishing. We add points. CRITICAL needs several strong signals.

9. Extension

Manifest V3. Auto-scans the tab. Same API as the website. Badge: OK / MED / HIGH / CRIT. On-page risk card. Full warning on HIGH/CRITICAL. If the backend is down it says UNAVAILABLE, never SAFE.

10. 2-minute pitch

Phishing copies banks and UPI apps. HTTPS and logos are not proof. PhishShield AI, in our CyberGuard repo, scores any URL with the same FastAPI engine from the website and the Chrome extension. We combine live intel, brand impersonation, Hinglish urgency language, and shady popup ads into a 0–100 score and a plain-English warning. This version is a multi-signal rule engine plus threat lists, not a trained CNN, and it stores scans in SQLite. Next: a supervised model and PostgreSQL. Today the value is consistent, explainable, real-time protection without invented results.
