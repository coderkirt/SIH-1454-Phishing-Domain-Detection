# Feature roadmap

## MVP (now)
URL scan, auth, dashboard, history, stats, short links, domain age, message paste analyzer, multi-link panel, reports, QR upload, explainable risk + confidence, Safe Open, export, delete analysis, extension Analyze All Links, SSRF hardening.

## V1
Tesseract OCR packaged with install docs, production CORS lockdown, per-user URL-history delete, Gmail/WhatsApp Web helper polish.

## V2
Android SMS companion, official Gmail OAuth, calibrated ML models, campaign clustering.

## Future
Attachment sandbox, native WhatsApp, more Indian languages, PostgreSQL at scale.
