# Jury Viva Question Bank

# A. Basic (Q1–Q30)

**Q1. What is this project?**  
Short: A phishing URL scanner with a website and a Chrome extension.  
Detailed: Users submit or browse a URL; a backend scores risk and explains it.  
Project: FastAPI `check-url` + React dashboard + MV3 extension.  
Do not say: “A CNN that is 99% accurate.”

**Q2. What is SIH 1454?**  
Short: Detect phishing domains that imitate genuine domains.  
Detailed: Typosquatting and brand impersonation, not only malware files.  
Project: Brand list + Levenshtein + leetspeak in `url_checker.py`.  
Do not say: We solve all cybercrime.

**Q3. What is phishing?**  
Short: A fake site or message that steals credentials.  
Detailed: Social engineering plus a lookalike domain or page.  
Project: We score the URL; we don’t capture the attacker.  
Do not say: We arrest phishing gangs.

**Q4. Who is the user?**  
Short: Anyone who received a suspicious link, including non-technical users.  
Detailed: Dual UI: Simple View vs Technical View.  
Project: Simple View in `warnings.py`.  
Do not say: Only CISOs.

**Q5. Frontend vs backend?**  
Short: UI vs API brain.  
Detailed: React renders; FastAPI analyzes.  
Project: Vite :5173, Uvicorn :8000.  
Do not say: Flask serves the React app.

**Q6. What is a REST API?**  
Short: HTTP JSON endpoints.  
Detailed: POST to create a scan; GET for stats.  
Project: `/api/v1/threat/check-url`.  
Do not say: `/api/analyze` unless you add it.

**Q7. GET vs POST?**  
Short: GET reads; POST sends a body.  
Detailed: Scans use POST because they have a URL body and create DB rows.  
Project: check-url is POST; stats are GET.  
Do not say: We GET the password.

**Q8. What is JSON?**  
Short: Structured text for APIs.  
Detailed: `{url, view}` in; `{risk_score, simple_view}` out.  
Project: Axios + Pydantic.  
Do not say: We store JSON as the only database.

**Q9. What is SQLite?**  
Short: A database in one file.  
Detailed: Good for MVP; weaker multi-writer than Postgres.  
Project: `backend/threats.db`.  
Do not say: We run PostgreSQL in production today.

**Q10. What is a table?**  
Short: Rows and columns.  
Detailed: users, url_checks, threats.  
Project: See `connection.py`.  
Do not say: Mongo collections.

**Q11. Primary key?**  
Short: Unique row id.  
Detailed: INTEGER AUTOINCREMENT.  
Project: `id` on all three tables.  
Do not say: We use UUID primary keys (we don’t).

**Q12. What is HTTPS?**  
Short: Encrypted HTTP.  
Detailed: Padlock ≠ genuine brand.  
Project: +5 if URL not `https://`. Not full cert check.  
Do not say: We verify EV certificates.

**Q13. What is a domain?**  
Short: The site name: sbi.co.in.  
Detailed: Registrable domain vs subdomain.  
Project: `get_registrable_domain()` handles co.in.  
Do not say: Domain = full URL.

**Q14. What is the extension?**  
Short: Chrome add-on that scans the current tab.  
Detailed: MV3 service worker + popup + content script.  
Project: Same API as the website.  
Do not say: It is on the Chrome Web Store as a paid product.

**Q15. What is a risk score?**  
Short: 0–100 danger points.  
Detailed: Sum of matched rules, cap 100.  
Project: LOW <30, MEDIUM <50, HIGH <70, else CRITICAL.  
Do not say: It is a neural probability.

**Q16. What is Simple View?**  
Short: Plain English warning.  
Detailed: For elderly / first-time banking users.  
Project: `build_simple_view`.  
Do not say: Generated by ChatGPT.

**Q17. What is Technical View?**  
Short: Evidence details.  
Detailed: Domain, DNS, HTTPS, intel label, ads.  
Project: `build_technical_view`.  
Do not say: Wireshark packet capture.

**Q18. How do you log in?**  
Short: Username + password → JWT.  
Detailed: bcrypt hash stored; token in localStorage.

Do not say: We store plaintext passwords.

**Q19. What is JWT?**

Detailed: HS256, claim `sub` = username.  
Project: `auth.py`. Signup/login set 7-day expiry in routes.  
Do not say: Refresh-token rotation (not implemented).

**Q20. Why React?**  
Short: Component UI, fast to iterate.  
Detailed: SPA with router and hooks.  
Project: React 19 + Vite 8.  
Do not say: Next.js SSR (not used).

**Q21. Why Python?**

Do not say: The extension is Python.

**Q22. What is CORS?**

**Q23. What is phishing vs malware?**
