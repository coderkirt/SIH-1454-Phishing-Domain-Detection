PHISHEYE

Real-time browser protection using the same detection engine as the dashboard.

  1. PHISHEYE intercepts the website before it opens. You see the gate, not the live page.
  2. The same FastAPI engine as the dashboard scans the address. Extra ads, popups, and buttons can mark a page FISHY.
  3. A clear result opens the site by itself. Fishy sites stay closed unless you press Open anyway. HIGH and CRITICAL stay closed.

The extension sends the page URL to your backend. It does not collect passwords, OTPs, or card numbers.
