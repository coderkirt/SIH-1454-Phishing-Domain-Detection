What data does PHISHEYE use?

The extension sends the website URL to the same backend as the dashboard. It does not collect passwords, OTPs, or card numbers. It does not read the page content.

Planned: richer privacy controls. Not implemented: zero-knowledge proofs, encrypted local database, federated learning.
