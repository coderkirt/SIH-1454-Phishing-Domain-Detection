# CyberGuard browser extension (Manifest V3)

This is a starter popup. It can read the current tab URL and send it to the FastAPI backend.

It does **not** intercept browsing or inject warnings into web pages yet.

## Load it in Chrome

1. Start the backend at http://localhost:8000
2. Open `chrome://extensions`
3. Turn on Developer mode
4. Click **Load unpacked**
5. Select this `extension` folder
